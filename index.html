About this project

Virtual Lab: DevOps Pipeline Simulation

Built for a college DevOps CI/CD lab, this dashboard is the visual front-end for a pipeline that runs entirely on free, static-friendly tooling.

  • CI
    Continuous Integration

    Every commit is automatically built and tested via GitHub Actions.

  • CD
    Continuous Deployment

    Passing builds are shipped automatically to production hosting.

  • VC
    Version Control

    All source history is tracked and reviewed on GitHub.

  • CO
    ChatOps

    Pipeline results are posted straight to a Slack channel.

  • CH
    Cloud-based Static Hosting

    The site itself is deployed on Netlify/Vercel with zero servers.
